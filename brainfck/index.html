Rules

SymbolValueDescription
'0Stops the program. New cells are initialized with this instruction
~1Does nothing and is passed over
<2Moves data_ptr left by the value in its data field, by default this value is 1.
>3Moves data_ptr right by the value in its data field, by default this value is 1.
+4Adds value of the data field to value at data_ptr
-5Subtracts value of the data field from value data_ptr
.6Prints value at data_ptr as character
:7Prints value at data_ptr as base-10 number
,8Reads character code from input and writes it to data_ptr
[9Jumps to address in its data field if value at data_ptr is 0. This address corresponds to the closing ] after compilation.
]10Jumps to address in its data field if value at data_ptr is unequal to 0. This address corresponds to the opening [ after compilation.
$11Swaps data and instruction value of a cell
?12Jumps to address in its data field with a 50% chance. Is otherwise passed over. The address corresponds to matching ! after compilation.
!13Does nothing on its own. Marks end of sequence triggered by ?
*14Dereference operator, sets data_ptr equal to value at data_ptr
&15Reference operator, sets value at data_ptr equal to data_ptr
^16Goto operator, sets instr_ptr to value at data_ptr
@17Here operator, sets value at data_ptr equal to instr_ptr
/18Toggles between data write mode, where the data_ptr points at the data field of a cell, and the instruction write mode, where the data_ptr points at the instruction field of a cell.
#19Load operator, sets data_ptr to the data field of the instruction cell. Created automatically when using a-z to address cells offset from the end of the compiled instructions by 1-26. # alone jumps to offset 0. ß on the other hand will create a jump to the very first cell of the tape, i.e. the first compiled instruction. You can use this simple mnemonic: ßtart
%21Wrap operator, wraps value at data_ptr such that it is mapped onto the range between 0 and the value in the instructions data field. By default, this value is 256. This makes it possible to use both wrapping and nonwrapping algorithms
=22Sets instr_ptr equal to data_ptr
°23Sets data_ptr equal to instr_ptr
